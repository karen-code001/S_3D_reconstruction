# 三维重建任务 Web 界面

这是一个无需构建工具的响应式用户端界面，覆盖三条核心流程：

1. 上传视频并展示后端返回的 `task_id`；
2. 输入 `task_id` 查询任务状态，支持每 3 秒自动刷新；
3. 输入 `task_id` 下载重建结果。
4. 输入 `task_id`，在主页面底部在线查看点云结果。

## 启动

在项目根目录运行：

```powershell
python -m http.server 5173 -d webui
```

然后访问 `http://localhost:5173`。也可以随控制节点启动后访问 `http://localhost:13000/ui/`（端口按实际启动参数调整）。

## 接口配置

页面右上角的“接口设置”可以修改 API 地址及接口路径。路径中的任务编号使用 `{task_id}` 占位符。

根据项目中现有路由扫描，当前初始值为：

- 创建任务：`/api/v1/tasks`（POST，JSON）
- 查询：`/api/v1/tasks/{task_id}`（GET）
- 结果查询：`/api/v1/tasks/{task_id}`（GET，读取 `result_url`）

上传遵循现有后端的两步流程：先创建任务并获取 `task_id` 与一次性 `upload_url`，再向该地址以 `file` 字段上传视频。

在线查看器支持直接返回的 PLY、PCD、XYZ、PTS、TXT，以及仅包含顶点的 OBJ 文件。若 TXT/XYZ 文件表头包含 `x y z inst_class sem_class R G B`，查看器会提供三种着色模式：RGB 模式直接使用 `R/G/B`，语义模式按 `sem_class` 稳定配色，实例模式按 `inst_class` 稳定配色，并显示类别/实例图例。缺少对应字段时，相应模式会自动禁用。若计算节点返回 ZIP、LAS/LAZ 或其他格式，需要先在重建流程中转换为受支持的点云文件。

点云查看区域已经合并到主页面底部，不再打开独立的 `viewer.html` 页面。

当查询、下载或在线查看使用的 `task_id` 尚未存在于本地最近任务时，页面会读取控制节点响应中的 `original_filename` 并保存。已存在的本地任务信息不会被控制节点返回值覆盖。

查询、下载或在线查看已存在的任务时，不会更新时间字段或改变该任务在最近任务列表中的位置。

最近任务中的每条记录都可以单独从当前浏览器删除；该操作不会删除服务端任务或结果文件。

“下载”操作位于“获取重建结果”标题右侧；查询、在线查看和下载按钮采用统一宽度并保持右侧对齐。

## 期望响应

上传响应至少应包含以下任一字段：`task_id`、`taskId`、`id`。查询响应可使用 `status` / `state` 和 `progress` / `percent`。下载接口既支持直接返回文件，也支持 JSON 中返回 `download_url` / `url` / `result_url`。

如前端与 API 不在同一域名，请在后端启用 CORS。生产环境建议由现有后端或 Nginx 直接托管本目录。
